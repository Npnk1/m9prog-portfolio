De opdracht

DP is een makelaar in industrieel en logistiek vastgoed in Oekraïne. Voor DP heb ik een website gemaakt met een catalogus van panden, een eigen pagina per pand en de onderdelen Diensten, Over ons en Contact. De site is in het Oekraïens.

Aanpak

Het ontwerp heb ik gemaakt in Claude Design en daarna omgezet naar code met Next.js (App Router), strikte TypeScript en Tailwind CSS v4. Ik werkte alleen, samen met Claude Code: Opus voor de planning en Sonnet voor het bouwen. In CLAUDE.md staan de regels voor de inhoud: geen verzonnen feiten, en onderdelen zonder bevestigde gegevens worden niet getoond.

Wat ik heb geleerd

Oekraïense tekst is langer dan de tekst in het ontwerp, daarom heb ik de titel kleiner gemaakt met clamp(). De controlescripts vonden fouten niet, dus die heb ik gerepareerd. Claude Code voegde functies toe waar ik niet om had gevraagd. Daarom heb ik in CLAUDE.md duidelijk vastgelegd wat wel en niet gebouwd moet worden.
