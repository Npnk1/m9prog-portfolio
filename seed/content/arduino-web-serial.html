De opdracht

In de module IoT leerde ik een Arduino programmeren en de gegevens daarvan in de browser tonen.

Aanpak

Op de Arduino draaien sketches die gegevens via USB versturen. Een webpagina leest die waarden uit met de Web Serial API van de browser en toont ze direct.

Wat ik heb geleerd

Hoe hardware en een webpagina met elkaar communiceren, en hoe je seriële data in JavaScript verwerkt.
